2. Descrição da Atividade

A atividade consistiu no desenvolvimento de um Portal de Entretenimento Digital utilizando HTML e CSS, com foco na aplicação de conceitos como estrutura semântica, estilização com Flexbox, uso de classes e IDs, além da publicação do projeto na web por meio do GitHub Pages.

Para apoiar o processo de desenvolvimento e aprendizagem, foi utilizada a ferramenta de Inteligência Artificial Claude (Anthropic), disponível em claude.ai. A IA foi consultada em diferentes etapas do projeto, desde a análise e correção dos arquivos de código até orientações sobre como publicar o site na internet.


3. Registro das Interações com a IA

A seguir estão registradas todas as interações realizadas com a Inteligência Artificial durante o desenvolvimento da atividade, apresentadas na ordem cronológica em que ocorreram.

Interação 1 — Análise do código do portal
Papel	Conteúdo da Interação
Usuário	Analise os códigos dentro das pastas que vou enviar e veja se está tudo correto. [Arquivos enviados: estilo.css, portal.html, reset.css]
IA (Claude)	Realizei a análise completa dos três arquivos do projeto portal-entretenimento. O resultado foi: 9 itens corretos (DOCTYPE/charset/viewport, ordem dos CSS, tags semânticas, atributos alt nas imagens, IDs correspondentes, Flexbox, transition/hover, object-fit, reset completo), 3 melhorias sugeridas (URLs de imagens sem parâmetros de otimização, CSS inline misturado ao externo, ausência de media queries para responsividade) e 2 observações (uso de CSS em três locais e ausência de box-sizing no reset). Em geral, o projeto está bem estruturado e sem erros críticos.

Interação 2 — Como inserir imagens no portal
Papel	Conteúdo da Interação
Usuário	Muito obrigado, porém, ainda necessito de sua ajuda, como faço para inserir as imagens que desejo no portal?
IA (Claude)	Expliquei as duas formas principais: 
Opção 1 — imagem salva no computador (arquivo local), colocando a imagem na mesma pasta do projeto e referenciando pelo nome no atributo src; 
Opção 2 — imagem hospedada na internet, copiando o link direto da imagem. Também informei os formatos aceitos (.jpg, .png, .webp, .gif) e a dica de usar imagens com largura entre 600px e 900px para melhor desempenho, já que o CSS usa object-fit: cover.

Interação 3 — Solicitação de imagens pela IA
Papel	Conteúdo da Interação
Usuário	Por favor, como seu conhecimento é infinitamente maior que o meu, faça a escolha das imagens para utilização no portal.
IA (Claude)	Escolhi imagens gratuitas e de alta qualidade do Unsplash para cada seção: Filmes e Séries (sala de cinema com poltronas vermelhas e pipoca em frente à TV), Música e Podcasts (fones de ouvido modernos e microfone de estúdio), Games e Tecnologia (controle de videogame iluminado e setup gamer com teclado RGB). Todas as URLs foram otimizadas com parâmetros ?w=640&auto=format&q=75 para carregamento mais rápido. Gerei o arquivo portal.html atualizado para download.

Interação 4 — Publicação no GitHub Pages via VSCode
Papel	Conteúdo da Interação
Usuário	Muito obrigado, mas tenho mais um pedido de ajuda. Estou usando o VSCode e preciso publicar esse portal no GitHub. Como faço isso?
IA (Claude)	Apresentei um guia passo a passo completo em 4 partes: Parte 1 — criar conta e repositório no GitHub (configurando como Public com README); Parte 2 — instalar o Git, clonar o repositório pelo VSCode usando Ctrl+Shift+P > Git: Clone; Parte 3 — copiar os arquivos para a pasta clonada (renomeando portal.html para index.html, obrigatório para o GitHub Pages) e fazer commit/push pelo painel de Controle de Código do VSCode; Parte 4 — ativar o GitHub Pages em Settings > Pages, com o link final no formato https://seu-usuario.github.io/portal-entretenimento/.


4. Reflexão sobre o Uso da IA

O uso da Inteligência Artificial como ferramenta de apoio ao desenvolvimento desta atividade mostrou-se eficiente e didático. A IA foi capaz de analisar os arquivos de código enviados com precisão, identificando pontos corretos e sugerindo melhorias de forma clara e organizada, sem substituir o raciocínio do estudante, mas complementando-o.

Um aspecto positivo foi a capacidade da IA de adaptar as respostas ao nível de conhecimento demonstrado nas perguntas, explicando conceitos como Flexbox, object-fit e GitHub Pages de forma acessível. Além disso, a geração do arquivo HTML com imagens otimizadas e o guia passo a passo para publicação no GitHub demonstraram como a IA pode acelerar etapas práticas do desenvolvimento.

Como ponto de atenção, é importante ressaltar que a IA é uma ferramenta de apoio e não substitui o estudo e a prática. As sugestões fornecidas devem ser compreendidas, avaliadas e aplicadas criticamente pelo estudante, garantindo o real aprendizado dos conceitos envolvidos.
